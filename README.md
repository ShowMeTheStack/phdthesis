# An Investigation of Side-Channel Security in Open-Source RISC-V Processors

Interactive companion to the Ph.D. thesis of Jyotiprakash Mishra, BITS Pilani, K. K. Birla Goa Campus.

Live at https://phd.jyotiprakash.org

The site is one self-contained page, `index.html`. It works offline and needs no server or build step. Open it in a browser.

It walks through the three contributions of the thesis with step-by-step demos:

- **NovelSCA**: 23 microarchitectural side-channel classes on six open RISC-V cores, checked on FPGA silicon.
- **ARCHER**: a cycle-accurate RISC-V emulator for attack and defence studies.
- **PACE**: a page-adaptive memory-encryption engine with formally verified masking.
